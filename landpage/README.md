# @mockmatch/landpage

Public marketing landing for MockMatch (Magic UI bento, beams, marquees).

## Dev

```bash
# from monorepo root
npm run dev:landpage
# → http://localhost:5175
```

## Env

| Variable | Default | Purpose |
|----------|---------|---------|
| `VITE_APP_URL` | `http://localhost:5173` | Product app origin for Log in / Get started |
| `VITE_DOCS_URL` | `https://docs.mockmatch.ai` | Public docs |

## Build

```bash
npm run build --workspace=@mockmatch/landpage
```
