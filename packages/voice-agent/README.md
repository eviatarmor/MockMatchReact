# `@mockmatch/voice-agent`

Product-agnostic **live voice-agent** chrome for interview / coaching surfaces:

- **VoiceAgentShell** — Ide-style chrome slot + resizable agent | chat (desktop) / stacked mobile
- **AgentStage** — robot presence + mute/end
- **ChatPanel** + **ConversationInput** — transcript + speech/text compose
- Host owns WebRTC / Pipecat transport, session setup, and i18n labels

> **Status:** private monorepo package. Shell only — no API keys or network.
