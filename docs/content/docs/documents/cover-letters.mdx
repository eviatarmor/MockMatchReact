Cover Letters uses the same document lifecycle as Resume Lab: list, create, import PDF, templates, canvas editor, history, collab, PDF export, and the in-editor AI rail. The editor is tuned for letter tone and structure rather than multi-section resume layout.

## Open Cover Letters

In the signed-in app: **Applications** area → **Cover Letters** (`/cover-letters`).

## Create or import

1. Open **Cover Letters**.
2. Choose **New cover letter** or **Import** (PDF under 5 MB).
3. Start from a template when you want a role-shaped shell.
4. Open the document to edit.

## Edit and AI assist

Edit on the canvas with autosave. Use history for prior versions. The **AI rail** supports section and selection attachments, same pattern as resumes. AI actions may use [credits](/docs/account/credits).

For job-specific letters from Discover, generate a **fit cover letter** on the job when that action is available (may cost credits). Keep a general letter in Cover Letters for reuse and editing.

## Export and collab

Export PDF the same way as resumes: editor export, Chromium print render on the API. Collab share rules match documents: active while the owner is in the document; `view` or `edit`; only the owner manages share. Details: [Templates, import, export, collab](/docs/documents/templates-import-export).

Length, voice, and role targeting: [Perfect cover letter](/docs/guides/perfect-cover-letter).
