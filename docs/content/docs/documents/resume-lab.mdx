Resume Lab is where you create and refine resumes: list → template or import → canvas editor → history, collab, PDF export, and AI assist.

## What you can do (product truth)

- Create a resume from a template or blank
- Import an existing PDF
- Edit on a document canvas with autosave
- Review versions and export PDF
- Share for collab while you are in the document
- Use the document AI rail (credit-gated when configured)

## In MockMatch

Go to **Documents → Resume Lab** in the signed-in dashboard.
