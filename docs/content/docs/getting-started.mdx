Get into MockMatch, understand the dashboard chrome, and pick one high-leverage next step: a document, a job, practice, or readiness.

## What MockMatch is for

You use one workspace to:

- Improve resumes and cover letters
- Discover roles and track applications
- Practice in interview-like formats
- See readiness and performance so prep stays organized

Success looks like always knowing the next useful action without juggling separate tools.

## Public landing

Marketing lives in the monorepo **`landpage`** app (not the product client). Locally: `npm run dev:landpage` → port 5175. It links to **Docs**, in-page changelog notes, **Log in**, and **Get started** on the product app. The product client `/` still enters the signed-in shell (or login gate).

## Sign in

1. Open the MockMatch app (or use **Log in** / **Get started** from the landpage).
2. Sign in with **email one-time password (OTP)**. Enter your email, then the code from the message.
3. If LinkedIn (or another social provider) is configured for your environment, you can use that path instead. Some environments leave social OAuth stubbed.

Access tokens are short-lived. Refresh stays server-side so you can stay signed in across devices without sticky sessions.

## First minutes on the dashboard

After sign-in you land in a signed-in shell:

- **Icon rail** (left): major areas, including Applications, Practice, Insights, Automation, and Help & support
- **Section nav**: pages inside the active area
- **Navbar**: breadcrumbs, **Ask** (product help chat), notifications, theme, **Feedback**, and credits

If the product prompts onboarding, fill profile basics first. A complete profile helps fit scoring and autofill later.

## Pick one first action

Choose based on where you already are in a search:

| If you… | Do this |
|---------|---------|
| Need materials ready | Open **Resume Lab** or **Cover Letters**, create or **Import** a PDF |
| Have a role in mind | Open **Discover**, or **Import Job** on **Applications** |
| Need interview reps | Open **Simulations** or **Question Bank** |
| Want a status check | Open **Readiness** under Insights |

You do not need to finish every area in one sitting. Closing one loop beats partial progress in four.

## Credits in plain terms

Some AI and collaboration actions use **credits**: fit documents, certain mock interviews, and related work. Free grants may apply. Top-up uses Stripe when the environment has billing keys configured.

The navbar shows remaining credits. Open **Billing** from the user menu for usage and packs. MockMatch does not claim unlimited free AI when an action costs credits. Details: [Credits & plans](/docs/account/credits).

## Where to get help in the product

- **Ask** (navbar): short answers about pages and how-tos
- **Help & support**: topic-based tickets (billing, bug, account, feature request, general)
- **Feedback** (navbar): anonymous product notes; no name or email in the payload
- **Docs** (this site): linked from Help & support; opens in a new tab
