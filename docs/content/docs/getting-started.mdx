## What MockMatch is

One calm workspace to improve materials, find and track roles, practice interviews, and see what to do next.

## First visit

1. Open the app and sign in with email OTP (or a social provider when configured).
2. Complete onboarding if prompted (profile basics).
3. From the dashboard icon rail, pick one high-leverage next step:
   - **Documents** — import or start a resume
   - **Jobs** — discover or track an application
   - **Practice** — start a simulation
   - **Insights** — check readiness
