Author practice items for every simulation format, then deploy them into **your** question bank. Deploys stay private to you; there is no team or global publish.

## Open Custom questions

In the signed-in app: **Practice** area → **Custom questions** (`/custom-questions`).

## Simulation types

The page lists every supported format from the product catalog:

| Format | What you author |
|--------|-----------------|
| Multiple choice | Stem, options, single / multi / order |
| Code run | Prompt + optional starter code |
| Dev workspace | Multi-file style prompt + starter |
| Terminal lab | Terminal-oriented coding prompt |
| Whiteboard | System-design style prompt |
| Spreadsheet | Case / formula prompt |
| Document | Document analysis writeup |
| Conversation | Interviewer prompt for voice practice |

## Create and deploy

1. Select a simulation type.
2. Fill in **title**, **domain**, **difficulty**, and the format-specific prompt fields.
3. Choose **Save draft**. The item stays private and does not appear in the shared bank yet.
4. On the draft row, choose **Deploy to my bank**. Only self-deploy is offered.

Deployed customs show a **Custom** badge in [Question Bank](/docs/practice/question-bank). Use **My custom** on that page to filter to your customs only.

## Practice

After deploy, open the item from Custom questions (**Practice**) or from Question Bank. Practice uses the same `/simulations/:questionId` dispatcher as global bank rows.

## What is not available

- Team or org-wide publish
- Global bank publish from this surface
- Editing someone else's custom questions (self-owned only)
