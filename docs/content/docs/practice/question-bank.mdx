The Question Bank is a shared global content bank: format, payload, and optional file content for practice. It fills as you import jobs or mark applications applied, with model-assisted generation and vector-backed semantic dedupe so near-duplicates stay out.

## Open Question Bank

In the signed-in app: **Practice** area → **Question Bank** (`/question-bank`).

## What you can filter

Browse by domain, difficulty, status, and format. Domains include areas such as coding, system design, data science, ML, security, DevOps, product, design, case study, consulting, behavioral, finance, marketing, sales, and clinical.

## Formats you may see

| Format | How you practice it |
|--------|---------------------|
| Conversation | Opens voice conversation practice |
| Code run / workspace / terminal | Opens IDE-style practice for the bank row |
| MCQ | Sequence with single, multi, or order variants |
| Whiteboard | Canvas practice for the question |

Whiteboard is practice-ready; generation of whiteboard items is optional depending on the generator path. Seed IDE labs stay in the exercise catalog, separate from bank rows.

## How questions get into the bank

1. **Import Job** on Applications pastes a description → questions generated once for that job
2. **Mark applied** from Discover → same once-per-job generation
3. Semantic dedupe reduces near-duplicate questions
4. **Custom questions** you author and **Deploy to my bank** — private to you, shown with a **Custom** badge

Use **My custom** on the Question Bank toolbar to show only your self-deployed customs.

You can still open tracks browse under Simulations; it is the same bank with the same filters.

## Suggested use

1. After you track or apply to a role, open Question Bank and filter to related domains.
2. Run a few items in the format you expect in the interview.
3. Check [Performance](/docs/insights/performance) over time; use [Readiness](/docs/insights/readiness) for next-step suggestions.
