Simulations is the practice home: recent sessions, featured interview tracks, and entry points into formats such as code run, conversation, terminal lab, dev workspace, multiple choice (MCQ), whiteboard, spreadsheet, and freeform document analysis.

## Open Simulations

In the signed-in app: **Practice** area → **Simulations** (`/simulations`).

## Sessions

Recent practice sessions merge voice and IDE attempts. Each retake is its own row. If you open an unfinished IDE exercise, you can **Continue** or **Start new**.

## Interview tracks

The featured tracks strip shows recent bank questions. **Browse all** opens `/simulations/tracks`, which lists the same global question bank as Question Bank, with the same filters (domain, difficulty, status).

Seed IDE labs (catalog exercises) remain available from direct URLs and session history labels. They are not listed as rows in the tracks table.

## Formats

| Format | What you practice | Entry pattern |
|--------|-------------------|---------------|
| **Bank question (any format)** | Practice from Question Bank or tracks | `/simulations/:questionId` |
| **Code run** | Timed coding labs with Run / Run tests where wired | `/simulations/code-run/:format` or bank URL above |
| **Dev workspace** | Freeform multi-file collab IDE | `/simulations/workspace` |
| **Terminal lab** | Shell-only multi-tab terminal with collab | `/simulations/terminal-lab` |
| **Conversation** | Live agent interview (robot + chat, voice pipeline) | Bank URL, or catalog `/simulations/conversation/:trackId` |
| **MCQ** | Single, multi-select, or order questions in a sequence | `/simulations/:questionId` |
| **Whiteboard** | Pan/zoom canvas: sticky notes, shapes, pen, connectors | `/simulations/:questionId` |
| **Spreadsheet** | Multi-sheet grid with formulas for case and finance drills | Freeform `/simulations/spreadsheet`, or bank URL |
| **Document** | Freeform Notion-style page for case writeups | Freeform `/simulations/page`, or bank URL |

### Code run notes

Code-run rooms support live collab (presence and share). **Bank** coding problems open at `/simulations/:questionId` (dispatcher mounts the IDE from the `questions` row). Legacy seed labs under `/simulations/code-run/:format` still exist for a few fixed demos. Some language run paths and full web-app run for multi-file React are still rolling out; do not assume every language is fully judged yet.

### Conversation notes

Conversation setup creates a voice session (credits may apply for mock interviews). The live path uses speech-to-text, an LLM, and text-to-speech on voice workers, with robot and chat driven by server events. If the voice pipeline fails, a mock path may still drive the UI. Tracks include examples such as behavioral core, product sense, and system-design talk. Camera analysis UI may be present without full backend analysis.

### MCQ notes

MCQ sessions run a same-domain sequence. Variants: **single**, **multi** (select all), and **order** (drag to reorder). Check an answer, move next, then see a summary.

### Whiteboard notes

Whiteboard practice uses a canvas shell with templates, autosave, and collab kind `whiteboard`. Practice opens at `/simulations/:questionId`. **Share** links use the same path with a `share` token only (the board id is resolved from the token).

The right rail includes a **Stencils** library (search + categories): architecture and diagram icons you place on the board. Icons are SVG stencils derived from open draw.io libraries; brand marks stay owned by their vendors and are for diagram use.

### Spreadsheet notes

Spreadsheet practice is a multi-sheet workbook: editable cells, formula bar, and sheet tabs. Freeform: `/simulations/spreadsheet`. From the question bank, Practice opens `/simulations/:questionId` with the case prompt and optional starter workbook from generation. Workbooks autosave; **Share** uses collab kind `spreadsheet` (`?share=` on the bank or freeform path).

### Document analysis notes

Document analysis is a freeform Lexical page (headings, lists, checklist, quote, code, slash menu). Freeform: `/simulations/page`. Bank Practice opens `/simulations/:questionId` with the prompt and optional starter outline HTML. Separate from Resume Lab sectioned editors. Collab kind `page`.

## History

Simulations history keeps **one row per exercise** (bank question or catalog track). Reopening the same practice continues the same workspace or board; there are no separate retake sessions for the same item.

## Collaboration on practice rooms

Bank practice share links land on `/simulations/:questionId?share=<token>` — no document id in the URL. Freeform spreadsheet, page, workspace, and terminal lab use their path plus `?share=`. The owner must stay in the room; leaving ends the live session for collaborators the same way document share works. See [Templates, import, export, collab](/docs/documents/templates-import-export).

## Exercise catalog

Catalog exercises live in Postgres (`practice_exercises`) with starter files in object storage under `exercises/<slug>/<version>/`. Local seed: `npm run db:seed:exercises` in the API package when you develop against empty storage.
