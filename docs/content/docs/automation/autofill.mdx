Autofill is the dashboard for the MockMatch browser extension (Chrome, Edge, Brave, Firefox). The extension fills application forms from your profile plus a chosen resume and cover letter. You always review before submit; the product does not auto-submit applications.

## Open Autofill

In the signed-in app: **Automation** area → **Autofill** (`/autofill`).

## What the dashboard shows

- Install status for the extension
- Activity log of recent fill work
- Entry points to settings such as theme, auto-detect, and prepare applications

## How a fill works

1. Install the extension for your browser from the product’s install guidance.
2. Sign into MockMatch so the extension can use your account data.
3. Pick profile fields plus a resume and cover letter (pick existing or AI tailor when available).
4. On an employer form, run fill from the side panel.
5. **Review every field** before you submit. Autofill never submits for you.

AI tailor steps may use [credits](/docs/account/credits).

## Safety rules to remember

- Review only: you own the final submit
- Prefer a job-specific resume or cover letter from [Discover](/docs/jobs/discover) when the role matters
- Keep Account Settings profile data accurate so fills stay consistent
