MockMatch is an interview-prep workspace. You improve documents, find and track jobs, practice in interview-like formats, and read readiness signals so you always know the next useful step.

This site is product help: what each area does, how to open it in the app, and how common workflows fit together. It complements in-app **Ask** (navbar chat) and **Help & support** tickets. It does not replace them.

## The prep loop

| Area | What you do |
|------|-------------|
| [Documents](/docs/documents) | Build and refine resumes and cover letters |
| [Jobs](/docs/jobs) | Discover roles and track applications |
| [Practice](/docs/practice) | Run simulations and review the question bank |
| [Insights](/docs/insights) | Read readiness and performance signals |
| [Automation](/docs/automation) | Autofill applications and record interviews |
| [Account](/docs/account) | Credits, billing, settings, and support |

Scores and charts exist to point you at a next action, not to decorate the dashboard.
