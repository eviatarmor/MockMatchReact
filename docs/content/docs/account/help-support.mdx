MockMatch gives you four complementary help channels. Pick the one that matches the job.

## Channels

| Channel | Where | Use when |
|---------|--------|----------|
| **Ask** | Navbar chat | You need a short product how-to or “where is X?” |
| **Help & support** | `/help` and user menu | Billing, bug, account, feature request, or general info with optional screenshots |
| **Feedback** | Navbar button | Anonymous product notes (message + page path/locale only) |
| **Docs** | This site (`docs.mockmatch.ai`) | Longer product maps and how-tos; also linked under Help & support (opens in a new tab) |

## File a support request

1. Open **Help & support** (`/help`) from the Help & support nav group or the user menu.
2. Pick a topic: billing, bug, account, feature request, or general info.
3. Describe the issue. Attach screenshots when they help.
4. Submit. Follow-up uses the signed-in account email.

## Send anonymous feedback

1. Click **Feedback** in the navbar.
2. Write what should improve or fix.
3. Send. Triage receives the message and page context without your name or email.

For structured account or billing problems, prefer Help & support so the team can reply to your account email.

## Ask vs Docs

- **Ask** is inside the app and optimized for navigation and short steps
- **Docs** is the public product map you are reading now

Neither invents features. If something is not built or is rolling out, the honest answer is that it is incomplete.
