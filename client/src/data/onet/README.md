# O\*NET-derived suggestion datasets

Static suggestion list for freeform skills autocomplete in the resume editor.

| File | Use | Source |
|------|-----|--------|
| `skills.json` | Resume skills-tag autocomplete | O\*NET-style basic/cross-functional skills + common tech |

Curated seed (not the full O\*NET dump) so the client bundle stays small. Edit `skills.json` directly to expand the list.

Attribution: O\*NET® concepts from the U.S. Department of Labor, Employment and Training Administration (USDOL/ETA). See [onetonline.org](https://www.onetonline.org/).
